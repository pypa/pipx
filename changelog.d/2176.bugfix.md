Fix bare local archives such as `.tar.xz` / `.tar.bz2` / `.tgz` / `.tar` being treated as
PyPI names instead of local paths.

The archive-extension list now matches pip and is matched case-insensitively, so `pipx install
pkg-1.0.tar.xz` resolves the local file the same way `./pkg-1.0.tar.xz` already did.
