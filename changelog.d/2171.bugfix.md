Fix inline script metadata being truncated by a `# ///` line inside a triple-quoted string.

A `# ///` line within a TOML `"""`/`'''` string prematurely ended the PEP 723
metadata block, so `pipx install` failed with `Unterminated string` for a valid
script. The block terminator is now recognized only when it is not inside a
triple-quoted string.
